## Why

Проект использует npm в качестве пакетного менеджера. Bun установлен в системе и является более быстрой альтернативой для установки зависимостей и запуска скриптов. Переход на bun сократит время установки и сборки.

## What Changes

- **BREAKING**: Замена npm на bun как пакетного менеджера
- Удаление `package-lock.json`, создание `bun.lock`
- Обновление скриптов в `package.json` для совместимости с bun (если необходимо)
- Обновление документации (README) по использованию bun

## Impact

- **Файлы**: `package-lock.json` → `bun.lock`, `README.md`
- **Зависимости**: Библиотеки unchanged; только менеджер пакетов
- **CI/CD**: Если есть скрипты сборки, нужно обновить команды npm → bun
- **Разработка**: Команды `bun install`, `bun run dev` вместо `npm install`, `npm run dev`
